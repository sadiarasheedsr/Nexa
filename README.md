# Nexa – Social Network

A modern, responsive social networking frontend built with **HTML5, CSS3, and JavaScript**. Nexa provides a social-media-style interface for stories, posts, likes, comments, friends, notifications, profiles, messages, and settings.

## 🚀 Live Demo
👉 https://sadiarasheedsr.github.io/Nexa/

## ✨ Features

- 🏠 Home feed with dynamic posts
- 📖 Circular stories and story viewer
- 📝 Create text posts
- 📷 Upload and preview images
- 🎥 Upload and preview videos
- ❤️ Like/unlike posts
- 💬 Add comments
- ↗️ Share/copy post links
- 👥 Friends and suggested people
- 🔔 Notifications and notification counter
- 👤 Profile view
- 💬 Messages interface
- ⚙️ Settings & Privacy
- 📈 Trending topics
- 🔔 Toast notifications
- 📱 Responsive desktop, tablet, and mobile layout
- ✨ Modern cards, gradients, shadows, and animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Google Fonts – Poppins
- FileReader API for image/video previews
- Clipboard API for sharing links

## 🚀 How to Run

### Open Directly

1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in a modern browser.

### Using VS Code Live Server

1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## 🏠 Main Sections

### Home
Includes Stories, the post composer, social feed, suggested friends, and trending topics.

### Stories
Users can open stories, move between stories, and view the animated story progress bar.

### Create Post
Users can write text, upload an image or video, preview media, and publish a new post.

### Post Interactions
Posts support likes, comments, and sharing. Counts update dynamically.

### Friends
Displays friends and suggested people with mutual-friend information.

### Notifications
Displays sample likes, comments, and friend-request notifications.

### Profile
Shows the profile cover, avatar, name, username, professional title, About section, and Edit Profile button.

### Messages
Provides a simple frontend messaging interface.

### Settings & Privacy
Provides a frontend settings interface with toggle-style controls.

## 🎨 Design

Nexa uses a clean social-network design with:

- White cards
- Rounded corners
- Soft shadows
- Green/blue gradients
- Circular avatars
- Sticky navigation
- Responsive columns
- Modal windows
- Story viewer
- Smooth transitions and animations

## 📱 Responsive Design

- **Desktop:** Three-column layout
- **Medium screens:** Right sidebar is hidden
- **Mobile:** Single-column feed with sidebars hidden

## ⚙️ JavaScript Functionality

The JavaScript maintains application state for posts, likes, friend requests, and stories. Posts are rendered dynamically, while the composer uses the browser `FileReader` API to preview uploaded images and videos.
